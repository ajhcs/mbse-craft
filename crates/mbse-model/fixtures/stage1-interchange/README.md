# Stage1 interchange synthetic fixtures

Original synthetic QA sources authored for this implementation under the repository MIT license. They contain no user mission, accepted engineering claim, observed measurement or external model content. Standard names/notation are referenced, not copied model-library definitions.

`supported-minimal.sysml` is one closed-profile System. The two `unsupported-*` files add standard language constructs outside this application profile. A valid language parse is distinct from profile admission; the importer must refuse the whole unsupported document and retain its exact source.

The adapter's closed draft ontology is embedded explicitly in every fixture so no external file, URL, JSON wrapper or hidden import supplies its meaning. Runtime parser/Pilot receipts are produced only by the integration owner's scheduled checks.
