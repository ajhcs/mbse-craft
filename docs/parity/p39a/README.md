# P39a: sealed native component admission transaction

This is the native transaction foundation for P39. It accepts an explicit caller-declared payload through the existing type model, profile metadata, global allocator and Editor history. The strict external source adapter/loss review is P39b; the rendered native Apply/Undo workflow is P39c. This PR does not parse or admit XML files by itself.

Prepare binds a sealed candidate to the exact native runtime, revision/raw state and whole Snapshot hash without changing the editor. The source model maps explicitly to a selected existing System without renaming it. Components and Part/Reference usages receive fresh native IDs; references resolve only within the explicit payload, never by equal native numbers or names. A fixed app-owned profile records member, primary pin, local source identity, source kind/name/namespace, source model identity/name and rule. The model fields are retained on every new correspondence, allowing independent source members in the same destination System. Optional Block declarations are documentary metadata on a component definition, not full SysML semantics or a new calculation engine.

Apply uses one existing Editor typed command and one model-history entry. Invalid payloads, foreign/stale plans, duplicate source identities, incompatible profiles, containment cycles, global quotas, allocator exhaustion and revision exhaustion refuse without partial publication. Undo removes the new accepted objects and metadata together, retains newer native/type raw drafts and never rewinds IDs. Redo restores the same accepted identities. Existing native records, all prior typed/behavior/parametric meaning, invalid journals and opaque namespaces stay intact.
