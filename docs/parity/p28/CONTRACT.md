# P28 editable native relation matrix

Build on P27 PR35 merge894e00b8. One matrix projects the existing Stage1 graph
and native record IDs, never labels or geometry. All native records are axes;
32-row/32-column pages retain full totals, stable numeric order and explicit
shortened labels. Scope membership and calculation dependencies are read-only.
Current editable families reuse existing commands: Capability contributes to
Mission (toggle), Objective subject (nullable single typed reference), Measure
for Objective (mandatory single reference, replacement only). Other typed/profile/
requirement relations are outside this native matrix; no full NoMagic matrix claim.

Wrong endpoint kinds, cross-System links and clearing a required Objective cell
are disabled with reason. Eligible hints do not authorize mutation: a retained
cell prepares the exact existing typed command on a clone; private runtime proof
binds native instance/full Snapshot/raw/counters and repeats the check at dispatch.
Changed bytes with reused counters, raw changes, cold runtime and off-page IDs
refuse. Selection alone preserves source. Reports/proofs have no deserializer or
public constructor; no matrix or edit authority is recovered from a project file.

Workspace tools/menu/default Ctrl+Alt+M route through the shared command catalog
and portable shortcut configuration. Matrix is an auxiliary editor: pending native/
views writes/gestures or other auxiliary windows block entry/edit/history/navigation;
other workspace file/history commands refuse until it closes. Explicit matrix
Undo/Redo uses existing joint model/view history. Exact axis selection changes
selection only. Role/page changes suppress old cells before rebuilding; external
source changes hide old cells until Refresh. Successful edit/history refreshes the
projection from the same graph used by the canvas/ledger.

Native acceptance opens the preserved native/views pair. A wrong-kind cell refuses;
removing a Capability link updates matrix and rendered graph ledger. Native Undo/
Redo and restoring the link preserve invalid raw/types/view geometry. Objective
subject replacement/clear/set uses current typed command; mandatory/read-only modes
refuse edits. Explicit native/views Save and cold Open agree with a fresh matrix
and diagram while original fixtures stay byte-exact. Global model counters may
advance; intentional accepted subject change is recorded separately from preserved
raw, other accepted records, typed extensions and all five view maps.

No new model/quantity engine, implicit relationship, migration or code execution.
Same-agent bounded Linux checks, no scale/platform/independent engineering/full
NoMagic/SysML/Craft claim. All56 broad specs and integrated exits remain unaccepted.
