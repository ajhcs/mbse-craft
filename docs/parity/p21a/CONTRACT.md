# P21a typed deletion and inverse history restoration

Build on merged P20 PR25 (4db52a28). P21 is split: this child covers typed
accepted definitions and members; P21b remains responsible for native-core
record deletion. The parent stays open until both children pass.

Prepare enumerates a bounded transitive dependency deletion: property owner/type,
usage owner/target, interface payload, port owner/contract/assignment and every
connector owner/endpoint/conveyed target. Defaults and explicit overrides referring
to deleted properties/usages are removed. Deleting an override's property alone
keeps its Part. No upward owner cascade or fresh semantic IDs. All unfinished
native and typed journals remain intact, including forms for deleted IDs.

Unknown namespace, native field, raw field or creation-form reference semantics
block the complete-supported-reference verdict and Apply. Existing opaque source
metadata is retained. This conservative schema admission is not a global standards
verdict. Preview requires canonical distinct positive typed IDs (at most64 roots),
explicit acknowledgement of dependent-record/value treatment, at most128 removed
records,128 value entries and512 known incoming references.

The sealed plan binds the full snapshot, native instance/revisions, exact views
origin/stamp and presentation digest. A stale edit, raw edit, view edit, foreign
instance/origin or reopen invalidates it. Direct native-editor or snapshot Apply
cannot bypass the coupled Views transaction. The candidate is private and cannot
be deserialized. Preparation and Cancel leave accepted data/layout/allocator exact.

One publication detaches affected qualified/unqualified port occurrences and
connector routes while retaining presentation IDs, geometry and visibility. Exact
inverse same-runtime model Undo restores them; Redo detaches and Undo restores
again. Newer invalid forms survive. Private before/after history proofs never gain
cold recovery authority. Actual native plus captured bound views/4 Save and cold
reopen retain accepted records, raw journals and detached presentation state.

positive test data, not a repair or acceptance of the original model.
