# P21b native-core deletion and reference treatment

Build on P21a PR26 merge66a56b04. Extend the same sealed preview/coupled transaction
to accepted native Stage1 records as well as typed records. Policy is explicit
dependent deletion, not unlinking: native System scope, Mission contributions,
Objective subject, Measure Objective ownership, Expectation source/System,
Stakeholder Organization affiliations/Actor membership and calculation output
bindings cause their referencing native owner to join the deletion closure.
Calculation dependencies come from the existing Stage1 definitions; no evaluator
or second model is introduced. Transitive consumers are listed and deleted.

Deleting a System includes its scoped native records, typed definition/interface
System memberships and their existing typed dependency/value cascades. At least
one System must remain or Apply refuses. Owned Environment Context items are listed
and removed with their parent, not exposed as independent top-level record roots.
Nonempty unsupported observations/inputs/imported source archives/unknown metadata
remain conservative holds. A supported-reference verdict is bounded to admitted
current schemas, not SysML standards or arbitrary opaque data.

Preview lists affected native occurrence/edge IDs in addition to typed ports/routes
and owned Context identities. Native dependent records, owned Contexts and value
entries are subject to existing128-item review limits, plus64 roots/512 references.
Private sealed native+views proof, stale/foreign refusal, explicit treatment
acknowledgement, Cancel and atomic publication remain unchanged from P21a.

All raw/creation journals, including calc generations and forms for deleted IDs,
remain exact. Allocators do not decrease or reuse IDs. An unresolved selection is
retained without pretending the deleted record resolves; Undo restores it. Native
records/definitions and exact two-view occurrence/edge identities restore through
same-runtime inverse model Undo; newer invalid deletion text survives Undo/Redo.
Captured native/views4 Save and cold reopen preserve remaining accepted meaning
and detached presentation without inventing preview/history authority.

Positive input is the actual fresh-bound controlled synthetic P21a checkpoint and
its explicit single opaque-field-removal provenance; original protected checkpoint
remains untouched and blocking. Tests include native contribution/subject/owner,
calculation-consumer chain, stakeholder/expectation/organization/actor references,
owned Contexts, last-System refusal, cross-scope System cascade, view/history and
captured persistence. Native checks must exercise real preview/Cancel/Apply,
Undo/Redo with invalid form, two-view native occurrence/edge restoration, protected
unknown hold and captured cold state. P21 position closes only with both children;
M04 integrated exit and all56 broad parity specifications remain unaccepted.
