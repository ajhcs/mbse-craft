## Exact settings adapter notes for implementers

`Settings` requires Serialize+DeserializeOwned+Default+Clone+PartialEq. Put serde(default) on each struct; do not deny unknown fields. APP_ID and SCHEMA_VERSION mandatory; migrate defaults Ok. SettingsStore::open(Location::Dir(PathBuf)) returns (store,LoadReport); get/update/tick(Instant)/flush are actual methods. tick returns status and next_deadline; arrange repaint deadline. `take_moved_aside` reports external bad edits. APP_ID mbse-craft maps to MBSE_CRAFT_CONFIG_DIR under Auto; Dir bypasses env/portable. Dir accepts relative paths, so app validates absolute authorized destination. Auto can fall back to cwd. Native deps: craft-atomic,serde,toml_edit0.25+serde,dirs7; tempfile dev-only. Shared tick/flush do synchronous small-file I/O: do not describe preference persistence as asynchronous unless an actual adapter makes it so. Recovery data is not preferences and must not be erased on settings reset.
