## Selected catalog contract and proposed tests

Catalog admission is separate from editable model admission. Start with a user-selected local folder and bounded files; no network, provider, script or solver execution. Require regular nonsymlink sources, safe relative index paths, strict duplicate-free metadata, bounded file/total/count/depth limits and declared SHA256 match. Retain original JSON bytes (including vendor keys/comments where valid JSON permits whitespace), source bytes and license text. Index entries identify exact file hashes; unresolved dependencies and unparsed/unsupported semantics remain explicit. Do not assume dependency metadata closes source imports. Exporting/redistributing package content is not enabled merely by successful browsing.

Use a synthetic MIT fixture and separately admitted licensed Architecture Design2.0.0 example for actual native browsing. Tests cover changed bytes, checksum mismatch, duplicate JSON/index keys, parent/absolute/Windows paths, symlink, malformed/oversize/depth limits and unknown-key/raw-byte preservation. Opening or failing a catalog must leave the active model/raw/history/save state unchanged. No generic `.sysml/.xmi/.json compatible` label.
