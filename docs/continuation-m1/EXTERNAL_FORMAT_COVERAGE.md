# External semantic projection version 1

`mbse-exchange` is an original Rust source projection. It never creates a native Snapshot or executes model behavior. Exact original input bytes, member bytes, hashes, namespace/type strings, stable source IDs, source byte ranges, raw attribute values and direct child text remain available. `fresh_copy` uses the real Craft atomic engine's private create-new operation, refuses overwrite and writes original bytes only.

- UML/XMI (`mbse-craft.external.uml-xmi/1`): UML20131001 Model/Package/Class/Component/Interface/DataType/Enumeration, Actor, Property, Port, Constraint/OpaqueExpression, Activity/Action, Message, Association/Connector/InformationFlow nodes. Explicit local type/source/target/client/supplier/general/specific/association/memberEnd/sendEvent/receiveEvent/covered ID references and child href/idref references are projected. Base-element profile overlays are retained as Stereotype nodes; no normative stereotype meaning is inferred. Other types/namespaces remain Unknown.
- MDZIP (`mbse-craft.external.mdzip/1`): projects `com.nomagic.magicdraw.uml_model.model`, otherwise exactly one .uml/.xmi candidate. Unknown members are retained. Diagram/layout and service/plugin members are not interpreted or extracted. Multiple alternative cores refuse ambiguity.
- Capella (`mbse-craft.external.capella-7/1`): namespaced Project/SystemEngineering, Logical/Physical/SystemComponent, ComponentPort/FunctionInputPort/FunctionOutputPort, Logical/Physical/SystemFunction and Component/FunctionalExchange source nodes; original ID references and unit/property strings are retained. All other identified types remain Unknown. Version/namespace declarations are diagnostic evidence, not metamodel validation. AIRD is separately openable as an identified XML source projection, with explicit diagram/style/cross-resource limitations. No sidecar or URI is fetched automatically.
- SysML textual (`mbse-craft.external.sysml-text/1`): pinned syntax AST package/definition/usage and selected explicit membership declarations, qualified-name plus exact hash/span identity, explicit typing/subsets/redefines/references/crosses/specialization targets. A bounded lexical resolver matches uniquely named local declarations from inner package scope outward and preserves original target/scope/resolution status. Duplicate candidates remain explicitly ambiguous. Imported targets and general SysML name resolution remain unsupported. Unprojected members get diagnostics. Original expression/unit/constraint text remains unevaluated in the source span.

UTF-8 only. DTD/entity declarations, unsafe ZIP paths, duplicate members, symbolic-link members, encrypted/unsupported compression, ambiguous cores, duplicate source IDs, oversize members/expanded totals, compression ratios above 200, excessive XML depth/nodes/references and parser resource bounds refuse. Nothing is extracted. Source tables preserve unknown data; successful projection is not native admission, semantic completeness, conformance, equation solving, diagram fidelity or engineering acceptance.

Limits: 32 MiB source/member, 64 MiB total expanded ZIP, 256 members, 100000 projected nodes, 200000 references, XML/member depth 96; textual parser uses the existing stricter bounded preflight. Metadata and source spans remain version-specific.

Dependencies inspected before build: roxmltree0.19.0 MIT OR Apache-2.0 (no dependencies/build script); zip0.6.6 MIT, defaults disabled, deflate only (byteorder/crc32fast/flate2 Rust backend), no build script. Existing serde/sha2/mbse-model/pinned Apache syntax and Craft atomic dependencies are reused. No services/network/runtime providers are needed. Full dependency audit and execution are owned by the single verifier slot. Only original synthetic MIT test models are committed. Authorized actual CATIA/Capella inputs stay outside Git and require separate receipts.

Exact URI qualification is required for every mapped type. Capella known classes use the observed exact modeller/la/pa/ctx/cs/fa7.0.0 URIs; UML uses exactly UML20131001. Stereotype overlays require exact supported SysML20181001 or UAF20211201 URIs and an explicit known base role. Wrong-version/substring false friends remain Unknown with structured namespace/version evidence and diagnostics.
