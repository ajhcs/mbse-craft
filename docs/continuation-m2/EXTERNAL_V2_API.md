# External semantic projection2 — writer/API release

Decision: MBSE-Craft owns a new `mbse-craft.external.semantic-set/2` source-projection contract. This is an additive Rust module `mbse_exchange::v2`, with explicit version2 profile strings for source-specific reports. M1 `ExternalDocument` and closed native `.kernspan`/`kernspan.stage1.sysml/1` persistence/admission APIs remain separate. No previously saved file is silently migrated. Original-byte copy remains a copy of the original artifact, never serialization of this projection.

The sole model writer owns `crates/mbse-exchange/**` and its focused tests/fixtures plus these M2 contract documents in its existing isolated model worktree. It may implement immediately from this pinned release while paired-fork qualification owns the sole Cargo/verifier slot. No Cargo/build, root workspace/lock, desktop UI, assurance source, shared cache, reference model or Kernspan writes belong to this lane. Root alone integrates; independent qualification follows sequentially. This is an authorized source release, not a request for another human approval.

Public boundary: `v2::open(primary: &Path)` returns a source-specific projection; an explicit `v2::open_set(primary: &Path, companions: &[SuppliedSource])` may admit named companions only after its aggregate-budget/source-set tests exist. SuppliedSource names a validated logical relative path, explicit physical local path and role. Never infer adjacent files, search ambient directories, fetch network references or read environment configuration.

Projection2 retains primary source hash/original bytes, every admitted source/member hash/bytes/role, exact artifact/member-scoped element keys, a deterministic full supplied-source-set digest, original namespace/classifier/attributes/direct text and locators. A typed key includes member path plus original ID; original strings never become numeric native IDs. Text anchors retain hash/span and disclosed generated identity. Duplicate IDs within a member refuse; same ID in two members is independently addressable. Every resolved reference names an actual retained key and retains its raw spelling/role, with stored/containment-derived provenance distinguished. Ambiguous/unsupplied/wrong-kind endpoints remain explicit.

The source-set digest uses a disclosed versioned canonical JSON tuple containing primary hash and lexically ordered logical path/hash/bytes/role entries for **all** admitted bytes, including opaque members and supplied companions. It is independent of local physical paths. Changing only AIRD/AFM/opaque/dependency bytes invalidates that context. Duplicate/canonical-path ambiguity refuses before hashing. No shared Kernspan wire-format compatibility is inferred.

Use source-specific `SemanticKind` categories for Capella Mission, Capability, Exploitation, Involvement, Component and independent actor/human flags, Constraint/ordered OpaqueExpression bodies+languages, Port/Exchange, Allocation, PropertyGroup/typed values and metamodel helper versus engineering unknown. Preserve exact source kinds and source-version claims from the pinned primary audit. Correct fa/7.0.0 ports/exchanges; refuse nonexistent cross-metamodel type pairs. Exact SysMLv1/UAF profile applications retain their base-element keys. Formula text, empty bodies, source units and guards stay unevaluated; source scalar values do not become native calculation results.

Bounds: primary32MiB, source/member16MiB for additional files, expanded complete set64MiB,256totalmembers, depth96,100kprojectednodes/200krefs; XML node builder must have a finite node budget. Add DTO preflight counters before cloning:128attributes/node,64KiB/value,1MiB direct text/node,16MiB aggregate attributes and16MiB direct text,32MiB serialized report,512diagnostics and512losses with explicit truncation. Retain source bytes even when a typed interpretation refuses; partial reports must say which stage refused. Do not implement archive extraction, executable hooks, external entities, generators or a Java runtime.

A source-level editable-slice candidate may be represented separately only after the exact editable field/relation subset and reversible command contract are specified. Until then provide an actionable admission preview/refusal, never silently call the generic Stage1 importer. Whole-candidate loss/refusal names unsupported engineering semantics and leaves active native state unchanged. Immutable source inspection is not editable admission. Root will implement desktop controls against this versioned API after source contract review; no unqualified first-ID fallback or stale preview acceptance.

Initial vectors are the24 NOT RUN oracles from TEST_ORACLES.json plus exact scoped-ID/companion-byte-change/output-budget negatives. Only original synthetic fixtures enter distributable source. Actual private reference receipts contain hashes/counts/coverage/loss, not proprietary source contents. Run actual source/native tests before claiming any typed coverage, admission or compatibility.
